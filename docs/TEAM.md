# 三人分工与权限

| 成员 | GitHub 账号 | 建议负责 | 交叉评审 |
| --- | --- | --- | --- |
| 仓库负责人 | xhljxtlaa | 环境、D435i 驱动与标定 | 检查算法 PR 的话题、单位和数据 |
| 成员 2 | 待填写 | ORB3、轨迹分段、稀疏地图 | 评审 VINS 修改 |
| 成员 3 | 待填写 | VINS 深度/IMU、跟踪失效恢复 | 评审 ORB3 修改 |

这是建议分工，可由小组修改。仓库负责人在 GitHub Settings → Collaborators 中邀请另外两个账号，授予 Write；组员接受邀请后即可克隆私有仓库、推送分支和提交 PR。不需要共享个人 GitHub 密码或密钥。

建议 main 至少一人评审后合并。若账号套餐支持相应分支规则，可配置必需的 `offline-checks` 状态检查与 1 个批准。这里尚未配置远端规则或邀请具体成员。
